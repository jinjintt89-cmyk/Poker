## 🚀 Quick Start

1. Open the [Live Demo](https://8e1c966e.htmltourl.app/) in any web browser.
2. Start playing immediately — no downloads or setup required.

## ✨ Features

* **Instant Play:** Runs 100% in the browser with fast loading times.
* **Interactive Poker Mechanics:** Play through hands directly on screen.
* **Lightweight UI:** Clean, responsive design built without heavy frameworks.

## 💻 How to Run Locally

1. Clone or download this repository to your computer.
2. Open `Hello.html` directly in your browser (Chrome, Firefox, Safari, Edge).

## 🛠️ How It Works

The game logic, card dealing, and UI components are built using standard web technologies (HTML, CSS, and JavaScript). All state management and hand evaluations run entirely client-side for immediate response times.
